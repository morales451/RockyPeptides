# Surface: home landing page (app/page.tsx)

Mode: Persuade. Audience: skeptical Houston adults arriving from a dealer's link, mostly on phones. Action: leave a phone number to talk to a real person. Proof: plain facts, real prices, the five Reddit posts; nothing fabricated. User asked: copy as simple as possible, empathetic to people who want to learn before taking a peptide.

## Direction contract

THESIS: Every section is an honest facts label, ruled like the Nutrition Facts panel every dieter has read a thousand times. Refuses the category default: gradient wellness hero, rounded pastel cards, molecule clip-art.

OWN-WORLD: The page is the package; labels are printed on it. Package field is the logo's mint, owning a third or more of every viewport, alternating with logo-navy bands. Labels are white panels in navy ink with a 2px navy border and the label rule grammar: 10px bar, 5px bar, 1px hairline. Rows set name left, value right. One family, Archivo variable: black-expanded titles, semi-condensed row labels, regular prose, tabular numerals. Asterisk footnotes carry every caveat. No radius, no shadows, no gradients, no eyebrow kickers.

STORY: The visitor reads facts in plain words, sees who should not use it, how to use it safely and what it costs, then leaves a phone number for a real person.

FIRST VIEWPORT: Mint field. Headline "Heard a lot about GLP-3s?" in black-expanded navy, one empathetic line under it. Beside it (below it on phones), the "GLP-3 Facts" label: per-week serving, a big "Receptors targeted 3" row, three receptor rows, price row, footnote, and a working phone field that carries the number into the contact form.

FORM: Facts label (Nutrition Facts panel grammar), my first-ranked grounded candidate, chosen as the pick card. Seed key 47f28742. Build path: code-led (no image generation). Signature interaction: label rules print in on scroll (bars draw left to right, rows tick in once); the projection tool is a live "Your Projection Facts" label recomputing as you type.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
